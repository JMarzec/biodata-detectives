# BioData Detectives - Quick Start for Event Staff

## ⚡ **5-Minute Setup**

### **Step 1: Access Admin Panel**
- Go to: `/admin` on any computer
- No password needed (for now)

### **Step 2: Display QR Code**
- QR code is automatically generated
- Project it on a large screen
- Players scan with their phones

### **Step 3: Players Start Playing**
- Each team enters a name
- Chooses Normal or Expert Mode
- Plays 9 questions across 3 rounds
- Takes 5-10 minutes per team

### **Step 4: Monitor Leaderboard**
- View live rankings in admin panel
- Or display `/leaderboard` on projector
- Refreshes automatically every 5 seconds

### **Step 5: End of Event**
- Export scores as CSV
- Announce winners
- Reset leaderboard for next event

---

## 🎮 **How the Game Works (Simple Version)**

**Players answer 9 science questions about genes, cancer, and nutrition.**

- **Correct answer** = 100 points
- **Fast answer** (under 30 sec) = +20 bonus points
- **Expert Mode** = Harder questions, faster timer, 1.5x score multiplier

**Highest score wins!**

## 💡 **Pro Tips**

1. **Display QR code prominently** - Use a projector or large monitor
2. **Show leaderboard live** - Keeps players engaged and competitive
3. **Announce milestones** - "New high score!" or "Team X is in the lead!"
4. **Encourage teams** - Multiple people can discuss answers on one phone
5. **Export results** - Save scores for records or social media

## 🔧 **Troubleshooting**

### **QR Code not showing?**
- Refresh the admin panel page
- Check internet connection
- Try a different browser

### **Leaderboard not updating?**
- Wait 5 seconds (auto-refresh interval)
- Manually refresh the page
- Check that players have submitted their scores

### **Game is slow?**
- Check WiFi signal strength
- Reduce number of devices on network
- Refresh the page

### **Need to reset scores?**
- Go to Admin Panel
- Click "Reset Leaderboard"
- Enter admin password (default: biodata-admin-2026)
